PROOF OF THOUGHT

Complete Technical & Architectural Manual: From Concept to Blockchain Execution

Overview: This guide explains the complete technical architecture of Proof of Thought — an Android dApp built using React Native, Rust/Anchor smart contracts, Metaplex NFTs, IPFS, and the Solana Mobile Wallet Adapter. Use this manual to prepare for presentations, team study, and viva voce defense.

2. The End-to-End Pipeline: The Journey of a Thought

The entire system functions as a 5-stage pipeline connecting mobile hardware, decentralized storage, and on-chain state:

  [Phone Microphone / Text Input]
               │
               ▼
  [1. Hardware Capture: expo-audio .m4a & React State]
               │
               ▼
  [2. Decentralized Storage: Multipart IPFS Pinning via Pinata] ──► (Returns permanent CID)
               │
               ▼
  [3. Tokenization: Metaplex Umi NFT Minting (POT Token)] ───────► (MWA Signs via Phantom)
               │
               ▼
  [4. Integrity Verification: SHA-256 Hashing & Rust Anchor PDA] ──► (Immutable on-chain proof)

  [5. Monetization: Peer-to-Peer On-Chain Escrow Marketplace] ───► (SOL Payment + IP Transfer)
STAGE 1 Hardware Capture (Text & Voice Audio) React Native / Expo

Users capture ideas either through formatted text (up to 280 characters with live progress metrics) or by recording spoken thoughts. The audio recording utilizes expo-audio, directly accessing Android hardware microphone buffers to produce an optimized MPEG-4 AAC (.m4a) binary file in the app's sandboxed storage.

STAGE 2 Decentralized Archival (IPFS via Pinata) IPFS / Axios

Storing audio or arbitrary text directly inside Solana accounts incurs state rent fees (~0.00089 SOL per 100 bytes). To prevent blockchain bloat, our architecture offloads heavy data to the InterPlanetary File System (IPFS). The audio binary is uploaded via multipart/form-data to Pinata's pinning gateway, and an industry-standard NFT JSON metadata schema is generated: 

{
  "name": "Proof of Thought #172839",
  "description": "Minted on Solana via Proof of Thought",
  "thought": "Decentralization guarantees sovereignty over human creativity.",
  "author": "8fCUzqY4XYj7Gkc8PGkumb58iiecS9bWX9mmjnPRdRS6",
  "timestamp": "2026-10-08T14:15:00Z",
  "audioUri": "https://gateway.pinata.cloud/ipfs/QmVoiceNote..."
}
STAGE 3 NFT Tokenization (Metaplex Umi on Devnet) Solana / Metaplex

The app leverages Metaplex Umi (@metaplex-foundation/mpl-token-metadata) to mint a standardized Non-Fungible Token on Solana Devnet with symbol POT. The token's metadata points permanently to the IPFS URI. Phantom signs and pays the network transaction through the Mobile Wallet Adapter protocol.

STAGE 4 Cryptographic Integrity (Rust / Anchor Smart Contract) Rust / Anchor

An NFT URI points to off-chain data. To ensure mathematical tamper-proofing, the app computes a SHA-256 hash of the thought text. This 32-byte digest is registered in our custom Anchor program written in Rust (programs/thought-registry/src/lib.rs).

The contract allocates a Program Derived Address (PDA) with seeds ["thought", nft_mint_pubkey] and stores: 

#[account]
pub struct ThoughtRecord {
    pub author: Pubkey,         // 32 bytes: Creator wallet
    pub mint: Pubkey,           // 32 bytes: NFT address
    pub content_hash: [u8; 32], // 32 bytes: SHA-256 fingerprint
    pub timestamp: i64,         // 8 bytes: Immutable clock timestamp
    pub bump: u8,               // 1 byte: PDA bump seed
}

How Verification Works: When any user opens the thought card, the app recalculates the SHA-256 hash client-side and queries the PDA from Solana. If the hashes match, it displays the glowing [✓ VERIFIED ON-CHAIN] badge.

STAGE 5 P2P Monetization & Transfer of IP (On-Chain Marketplace) Marketplace Escrow

Creators can monetize their ideas, poems, melodies, or startup notes. When a creator taps [ LIST FOR SALE ], the listing price in SOL is recorded on-chain.

When another user browsing the Public Feed taps [ ⚡ BUY IP RIGHTS ]:

  1. The buyer signs a transaction via Phantom.
  2. The SOL payment is transferred directly from buyer to creator.
  3. On-chain ownership of the digital asset transfers to the buyer.
  4. The thought dynamically migrates into the buyer's "My Thoughts" portfolio while preserving original author attribution.
