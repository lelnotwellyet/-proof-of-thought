Proof of Thought — Project & Architecture Guide

A Simple, Plain-English Guide to What We Built, Why We Used Solana, and How It Works

1. What is This App?

Proof of Thought is a mobile app on Android where users can write ideas (text) or speak them into their phone (voice notes), permanently save them to decentralized storage, and turn them into digital assets (NFTs) on the Solana blockchain.

Once minted, the app uses a custom smart contract to mathematically verify that the thought has never been edited or tampered with. It also includes an on-chain marketplace where creators can list their ideas or tunes for sale, and buyers can purchase them with SOL to take real ownership.

2. Why Solana Instead of Ethereum?

People often ask why we did not just build this on Ethereum. Here is the simple comparison:

Factor Solana (What We Used) Ethereum Plain English Explanation
Mobile Wallets Mobile Wallet Adapter (MWA) WalletConnect Solana lets our app open Phantom directly on the same phone in milliseconds. Ethereum relies on cloud relay servers that disconnect frequently.
Transaction Cost Less than $0.001 per action $2 to $15+ per action Our app is for everyday thoughts and voice notes. Nobody will pay several dollars just to record a 5-second thought.
Speed Less than 1 second (~400 ms) 15 seconds to several minutes When a user taps "Mint" or "Buy", Solana confirms the transaction almost instantly, just like a regular mobile app.

3. The 5 Steps: How a Thought Travels Through the App

Here is what happens step-by-step from the moment a user opens the app to when a thought is on the blockchain:

Step 1: Connecting the Wallet

The user taps Connect Wallet. The app uses the Solana Mobile Wallet Adapter (MWA) to open the Phantom wallet app on the phone. The user approves the connection. The app only receives the user's public address (their public key) — it never sees or touches their private keys.

Step 2: Recording or Typing the Thought

The user can either type text (up to 280 characters) or tap Record to speak. When recording voice, the app uses the phone's microphone to save a small audio file (.m4a) on the phone.

Step 3: Storing on IPFS (Pinata)

Storing audio or long paragraphs directly inside a blockchain is very expensive. Instead, the app uploads the audio file and a JSON text card (containing the thought text, author, and timestamp) to IPFS via Pinata. IPFS is a decentralized file storage network that gives us a permanent link (CID) to the file.

Step 4: Minting the NFT (Metaplex)

The user taps Mint as NFT. The app uses Metaplex (the official NFT framework on Solana) to create a token with the symbol POT (Proof of Thought). This token points to the IPFS link. Phantom opens on the phone, the user approves the small devnet fee, and the user is now the on-chain owner of that NFT.

Step 5: Verifying Authenticity (Our Anchor Program in Rust)

An NFT link points to an off-chain file. To guarantee that nobody ever edits the text later, the app calculates a SHA-256 fingerprint (hash) of the thought text.

It sends this hash to our custom smart contract written in Rust using the Anchor framework. The contract saves this hash in a special blockchain account called a PDA (Program Derived Address) along with the author's address and the exact blockchain timestamp.

Whenever anyone opens the thought, the app recalculates the hash and checks it against Solana. If it matches, it displays the glowing [✓ VERIFIED ON-CHAIN] badge.

4. The Marketplace: How Buying and Selling Works

Since each thought is an NFT on Solana, it can be bought, sold, and transferred peer-to-peer:

  1. Listing: The creator opens their thought, taps List for Sale, enters a price in SOL (e.g., 0.05 SOL), and approves in Phantom. The app marks the thought as for sale on-chain.
  2. Browsing: Other users browsing the Public Feed see the thought with a price tag (e.g., [ 0.05 SOL ]).
  3. Buying: When someone taps Buy IP Rights, Phantom opens on their phone. They pay the 0.05 SOL to the creator, and the ownership of the thought transfers to the buyer.
  4. Ownership Update: The thought now shows up in the buyer's My Thoughts collection, while permanently keeping the original author's name credited in the history.

5. Quick Summary of Technologies Used

  • React Native & Expo: Builds the cross-platform mobile interface and handles audio recording through phone hardware.
  • Solana Mobile Wallet Adapter (MWA): Securely connects the app to Phantom on Android without handling private keys.
  • IPFS & Pinata: Decentralized file storage that permanently hosts voice files and metadata.
  • Metaplex (Umi): The standard on Solana used to mint and manage NFTs.
  • Anchor & Rust: The framework and programming language used to write our on-chain verification and escrow logic.

6. Team Division (3-Person Work Breakdown)

Person 1: Smart Contract & Blockchain Logic

Wrote the custom Anchor program in Rust (programs/thought-registry/src/lib.rs), designed the PDA account structures, and handled the on-chain registry instructions.

Person 2: Verification Engine & Storage

Built the cryptographic SHA-256 verification logic (utils/verifyThought.ts), the detail view screen, and the IPFS upload pipeline for voice notes and metadata.

Person 3: Mobile App & Marketplace Systems

Integrated the Solana Mobile Wallet Adapter in walletStore.tsx, built the marketplace listing and buying flow, designed the retro UI components, and compiled the standalone Android APK.
